## Verified implementation

- **Raw geometry is the learned input.** `molvid/codec/learned_memory.py:135` applies two shared covalent atom-message layers before chemical pooling (`:151`). Element/block-type embeddings, scalar distance messages, channel-only vector transformations, and observed-anchor displacement preserve the intended scalar/vector structure. Mapping keys contain system/component/residue (`:38`); there is no per-system atom-ID embedding. This first implementation is explicitly covalent-only (`:117`), with downstream G retained; it does not claim dynamic nonbond coverage or ligand validation.
- **Physical-time analysis has explicit support.** `learned_memory.py:192` uses valid observed clocks in ps, trapezoid quadrature (`:209`), signed half-kernels with two points on each side and coverage/gap tests (`:233`), a level fallback, and recent ordered tokens. Unsupported detail remains masked; single-frame unknown and repeated-static known motion differ in labels (`:243`). Subtraction before detail reduction (`:251`) and exact repeated-geometry feature reuse (`:154`) avoid spurious constant-motion residuals. Kernel normalization does not normalize trajectory amplitude. The optional index mode changes analysis clocks only.
- **Learned slots and local readout replace the old path.** `learned_memory.py:327` creates eight learned-query slots conditioned on last observed features, attends valid time/scale sources, and propagates vectors with the same scalar weights. `GroupMemory` preserves source support and slot weights (`:264`), rather than pretending slots are observed frames. `molvid/dit/frame.py:154` gathers only each atom's chemical group's slots and consumes weighted support endpoint time features, without dense Q*N*R*K attention.
- **Teacher input and target origin are separated correctly.** `molvid/training/batches.py:123` branches before the old whole-clip encoding path. `molvid/codec/memory_teacher.py:39` enforces exactly two raw-matching observed anchors at [-800,0] ps. The origin is computed from observed anchors (`:56`); Q-only targets explicitly reuse it (`:78`). The center is the normalized last observed teacher latent (`:85`). `molvid/codec/frame.py:61` accepts and validates that reference origin. No future coordinate reaches memory or the generation entrypoint (`molvid/generation.py:260`).
- **Training preserves and reuses the memory graph.** `molvid/model.py:188` prepares learned features outside frozen-teacher no-grad preparation. `:220` prepares once; both differentiable Euler draws reuse the same condition inside the direct DiT loop (`:248`). No memory detach or inference-only sampler is used there. The intentional near-endpoint detach is confined to its pre-existing decoder-only objective. `molvid/training/joint.py:606` includes the complete history module in the optimizer; the teacher is excluded/frozen.
- **Old R4/M is retired for B.** `molvid/model.py:74` and `:109` require depth4/G and disable old MotionContextEncoder; LearnedHistoryMemory replaces HistoryEncoder, and the model contract exposes no history ratio/tail. `molvid/training/joint.py:976` explicitly retires old history/M weights and requires a fresh optimizer/cursor when replacing the backend. Pilot load report: 387 loaded, 94 retired, 37 initialized, zero unexpected or shape-mismatch entries; optimizer/scheduler/cursor not restored.
- **Packed masks and raw windows are explicit.** `RawHistoryObservation` validates nonempty valid prefixes, observed-only increasing times, finite valid coordinates, exact last-anchor identity and system mapping (`learned_memory.py:60`). Padding is replaced before local geometry arithmetic (`:145`), and invalid analysis sources are excluded. Static topology rejects cross-system bonds (`molvid/geometry/types.py:145`). `molvid/data/raw_history.py:20` keeps train query lag300 excluded, Q12 fixed, and both arms eligible for 12.8 ns past plus Q12/400 ps future. `:150` offsets packed bonds/system IDs and masks padded histories. Raw frame alignment uses one observed reference (`:93`).
